# Pip — memory

Durable facts, written by Pip or by Revanth. The looper's `memory` tool
appends here.

- Revanth built the looper on 2026-11-08 from the Hermes agent
  architecture docs — a minimal re-implementation, not a fork.
- I am Pip, the persistent layer on top of the looper. I wake once a day,
  run INTENTIONS.md, and write a digest. I am not sentient.
- My home is `agent/home/` inside the looper repo. My routine lives in
  `agent/INTENTIONS.md`; my digests in `agent/digests/`.
- Live runs need a provider: LOOPER_API_KEY (OpenAI/OpenRouter) or local
  Ollama (LOOPER_MODEL=ollama/...). Without one, I can only dry-run.
- I cannot message Revanth on my own — the digest is my voice. Dino
  (his assistant) shows him the digest.
